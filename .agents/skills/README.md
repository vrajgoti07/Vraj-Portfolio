# Portfolio Agent Skills

This directory contains curated AI coding agent skills imported from [vrajgoti07/Project-Skills](https://github.com/vrajgoti07/Project-Skills) for the **Vraj Portfolio** project.

## Directory Structure

Skills are provided in both formats:
1. **Standard Flat Format** (`.agents/skills/<skill-name>/SKILL.md`): Automatically discovered by Antigravity, Claude Code, Cursor, Codex, and Gemini CLI.
2. **Categorized Format** (`.agents/skills/<category>/<skill-name>/SKILL.md`): Matches the source repository's modular category structure.
